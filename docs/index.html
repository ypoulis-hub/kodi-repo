YPoulis Kodi Repository

Install once, auto-update both add-ons. The recommended way to keep YouTube Music for Kodi and MotoGP VideoPass for Kodi current.

⬇ Download repository.ypoulis-1.0.0.zip View on GitHub

Install (one-time)

  1. Download repository.ypoulis-1.0.0.zip using the button above.
  2. In Kodi, open Settings → Add-ons → Install from zip file.
  3. Select the downloaded ZIP. Kodi installs YPoulis Kodi Repository.
  4. Then open Install from repository → YPoulis Kodi Repository and pick the add-on(s) you want.
  5. That's it — Kodi will keep them up to date automatically.

First-timers may need to enable Settings → System → Add-ons → Unknown sources so Kodi will install ZIPs from outside the official Kodi repo.
